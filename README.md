# ⚡ FlashDrop

**FlashDrop** — это анонимный, эфемерный мессенджер со сквозным шифрованием (E2EE) и поддержкой PWA. Проект создан как приватный инструмент для общения с семьей и друзьями, где безопасность и конфиденциальность стоят на первом месте.

Сервер выступает исключительно в роли «слепого курьера»: он пересылает зашифрованные сообщения, но не хранит их, не записывает в логи и не имеет доступа к ключам расшифровки.

## ✨ Основные возможности

*   🔒 **Сквозное шифрование (E2EE):** Сообщения, файлы и голосовые шифруются прямо в браузере алгоритмом AES-256-GCM. Ключ передается только в хэше URL (после `#`) и никогда не попадает на сервер.
*   🫥 **Эфемерность:** Сервер не использует базу данных. Если создатель закрывает вкладку, комната удаляется из памяти сервера через 30 секунд.
*   🔑 **Защита паролем:** Доступ к созданию комнат защищен общим кодом доступа (Access Code). Устройства запоминаются с помощью токенов.
*   📱 **PWA (Progressive Web App):** Приложение можно установить на главный экран смартфона (Android/iOS), и оно будет работать как нативное.
*   🎤 **Голосовые сообщения:** С поддержкой кастомного таймера и кроссплатформенным воспроизведением (WebM / MP4 для iOS).
*   📎 **Файлы и картинки:** Отправка файлов до 35 МБ с красивым полноэкранным просмотром изображений (Lightbox) и очисткой памяти браузера (Blob URLs).
*   💬 **Современный чат-интерфейс:**
    *   Уникальные никнеймы с возможностью выбора цвета.
    *   Коронка 👑 для создателя комнаты.
    *   Статус «В сети» (Online/Offline).
    *   Функция «Ответить» (Reply) на сообщения.
    *   Удаление сообщений (у себя или у всех).
    *   Исчезающие сообщения (режим «Секрет» на 30 секунд).
    *   Сохранение истории при случайном обновлении страницы (F5).
*   🔇 **Без логов и трекеров:** Полное отсутствие аналитики и сбора персональных данных.

## 🛠 Технологический стек

*   **Frontend:** Vanilla JavaScript, Tailwind CSS (через CDN), Web Crypto API, Service Worker.
*   **Backend:** Node.js, Express, Socket.io (WebSockets).
*   **Хостинг:** Рассчитан на деплой на Render / Railway / Vercel (Node.js окружение).
